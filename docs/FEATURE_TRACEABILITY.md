## 1. Classification Categories

To ensure absolute transparency and prevent ambiguity, every requirement is tagged with one of four implementation categories:

1. **`Real Kernel Mechanism`**: Genuine bare-metal x86-64 kernel software running in Ring 0 inside QEMU / hardware.
2. **`Host-Side AI / Tool Component`**: High-level intelligence, tool registry, or transport running as host companion services.
3. **`Educational Algorithm Simulation`**: Mathematical/theoretical models executing deterministically to demonstrate textbook OS concepts without pretending to be native hardware routines.
4. **`Hardware / Architectural Boundary`**: Conscious design limits or platform constraints documented in [`docs/LIMITATIONS.md`](LIMITATIONS.md).
